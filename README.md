# 🎓 منصة MK التعليمية

منصة تعليمية تفاعلية متعددة الأقسام (بنمط TryHackMe + Google Meet) تستوعب آلاف الطلاب.

## المميزات

- **7 أقسام أكاديمية**: أمن سيبراني، برمجة، هندسة وتقنية، غير تقنية، طبية، علمية، ثقافية (قابلة للإضافة من لوحة التحكم).
- **دورات ودروس**: تسجيل، تقدم، شهادات إتمام برمز تحقق + صفحة تحقق عامة `/verify`.
- **شهادات قابلة للطباعة**: صفحة شهادة رسمية تفتح في نافذة جديدة ويمكن حفظها PDF من نافذة الطباعة.
- **اختبارات تفاعلية**: كل درس يمكن أن يحتوي اختباراً، النجاح (50%+) ينهي الدرس تلقائياً.
- **معامل تطبيقية (Labs)**: خطوات تفاعلية داخل الدرس، إتمام كل الخطوات ينهي الدرس تلقائياً.
- **تحديات عملية (CTF)**: FLAG للتحقق + نقاط.
- **تقييم الدورات**: نجوم + تعليقات، متوسط التقييم يظهر في صفحة الدورة.
- **شارات وإنجازات**: تُمنح تلقائياً لإتمام الدورة الأولى، حل أول تحدي، إلخ.
- **مستويات XP وألقاب**: اكسب XP بإكمال الدروس والاختبارات والمعامل وحل التحديات وحضور البث — ترقَّ من "مبتدئ" حتى "أسطورة" مع أشرطة تقدم في ملفك ولوحة الترتيب.
- **تفاعل مباشر في البث**: دردشة حية، ردود فعل (👍❤️👏)، رفع يد واستدعاؤه من المضيف.
- **ملف متابعة الطالب**: لوحة مفصلة للأدمن تعرض تقدم الطالب، نتائج اختباراته، حضوره، تحدياته، تقييماته ومحادثاته.
- **وضع عدم الاتصال**: احفظ الدروس للقراءة دون اتصال وتصفحها من `/offline`.
- **إشعارات**: جرس في الشريط العلوي، إشعارات الشارات والجوائز والإعلانات.
- **مجتمع أسئلة وأجوبة** لكل دورة + إعلانات من الإدارة.
- **بحث في المنصة** (دورات وأقسام) من الشريط العلوي.
- **بث مباشر**: قاعات تتسع حتى 3000 مشاهد + **تقرير حضور** مسجل لكل قاعة.
- **رسائل خاصة**: محادثات خاصة بين الطلاب والأدمن مع إشعارات.
- **صفحة دورة محسنة**: مخرجات التعلم، المتطلبات، المدة، المدرب، اللغة.
- **مساعد ذكاء اصطناعي للأدمن**: يولّد أسئلة اختبار وأفكار تحديات ومخططات دورات كاملة من عنوان/موضوع (قاعدة معرفة محلية تعمل بدون مفتاح API).
- **امتحان نهائي لكل دورة**: إعداد نسبة النجاح والمدة، توليد أسئلة تلقائياً، الطالب يؤديه مرة واحدة ويحصل على النتيجة + XP.
- **الجدول الزمني والتذكيرات**: محاضرات وورش واختبارات يراها الطلاب مع عد تنازلي، وزر "تذكيرني" يرسل إشعاراً.
- **مجموعات دراسية تعاونية**: أنشئ مجموعات، انضم لمجموعات قسمك، لوحة نقاش مشتركة وانتقال ملكية عند مغادرة المالك.
- **الحقائب التدريبية**: مسارات تعلم تجمع عدة دورات بشهادة موحدة وتقدم إجمالي.
- **لوحة المحاضر**: إدارة طلاب دوراتك، إدخال الدرجات، إرسال إعلانات كإشعارات لطلاب دورتك.
- **سجل درجات يدوي**: درجات الطلاب في كل دورة + تصدير.
- **تقارير قابلة للتصدير**: تصدير الطلاب/التقييمات/الحضور/نتائج الاختبارات/التحديات بصيغة CSV متوافقة مع Excel (بدعم العربية).
- **نسخ احتياطي واستعادة**: إنشاء/تحميل/استعادة لقطات كاملة من لوحة الأدمن.
- **لوحة تحكم بمخططات**: توزيع الطلاب على الأقسام، تسجيلات الأشهر، أفضل 5 طلاب.
- **اختبار تحميل**: سكربت `npm run loadtest` لمحاكاة 3000 مستخدم متزامن.
- **لوحة إدارة بنوعين**:
  - **أدمن رئيسي**: كل الصلاحيات + إدارة الأدمن الفرعي.
  - **أدمن فرعي**: صلاحيات محدودة على أقسامه فقط، لا يرى بقية المنصة، ولا يدير أدمن آخر.
- **سجل تدقيق (Audit Log)** لكل إجراءات الأدمن.

## التشغيل السريع

### 1. الخادم (Backend)

```bash
cd server
npm install
npm run seed   # إنشاء البيانات التجريبية (مرة واحدة)
npm start      # يعمل على http://localhost:4000
```

> الخادم يستخدم `node:sqlite` المدمج في Node 22+ — لا حاجة لأي قاعدة بيانات خارجية.

### 2. الواجهة (Frontend) — وضع التطوير

```bash
cd client
npm install
npm run dev    # يعمل على http://localhost:5173 (ينقل /api للخادم)
```

### 3. الإنتاج (اختياري)

الواجهة تُبنى وتُقدم من نفس الخادم:

```bash
cd client
npm run build
# ثم شغّل الخادم فقط: http://localhost:4000 يقدم كل شيء
```

## البنية

```
server/          خادم Node.js (Express + node:sqlite)
  src/routes/    المصادقة، الأقسام، الدورات، الإدارة، البث، التحديات
client/          واجهة React + Vite
  src/pages/     صفحات الطالب ولوحات الإدارة
```

## تطوير قادم (وفق خطة التصميم)

- ربط البث بخادم SFU حقيقي (LiveKit) للتفاعل الصوتي/المرئي على نطاق واسع.
- محاكيات (Labs) معزولة افتراضية لكل طالب بنمط TryHackMe.
- PostgreSQL + Redis عند الانتقال للإنتاج والتوزع الأفقي.

## اختبار التحميل

```bash
cd server
npm run loadtest 3000 200   # 3000 مستخدم، 200 طلب متزامن
```

> نتائج تجريبية على جهاز محلي: 3000 طلب في ~1.7 ثانية، ~1700 req/s، بدون أي فشل.
